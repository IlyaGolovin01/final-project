# Бот технической поддержки «Продаем все на свете»

Telegram-бот на **pyTelegramBotAPI (telebot)**: отвечает на частые вопросы,
предлагает решения и передаёт сложные обращения живым специалистам в нужный
отдел. Все обращения к специалистам сохраняются в SQLite.

Подробное руководство для администраторов: **[docs/ADMIN_GUIDE.md](docs/ADMIN_GUIDE.md)**.

## Что умеет

| Требование | Как реализовано |
|---|---|
| Автоответы на частые вопросы | База знаний `data/faq.json` + нечёткий поиск по русскому тексту (`kb.py`), без внешних NLP-библиотек |
| Хранение запросов к специалистам | SQLite, таблица `tickets` (плюс `ticket_comments`, `users`, `faq_log`) — `db.py` |
| Текстовые сообщения | Свободный вопрос своими словами, кнопки тем, пошаговое создание заявки |
| Голосовые сообщения | Расшифровка через Whisper API (`stt.py`), включается одной настройкой |
| Понятный интерфейс | Нижнее меню из 4 кнопок, инлайн-навигация по темам, карточки заявок, кнопки 👍/👎 |
| Документация для администраторов | `docs/ADMIN_GUIDE.md` + встроенная справка `/help` |

Дополнительно: панель поддержки внутри бота (`/admin`) — списки открытых заявок
по отделам, ответ клиенту из бота, закрытие и переоткрытие, передача в другой
отдел, статистика, список вопросов, на которые бот не ответил, выгрузка в CSV.

## Быстрый старт

```bash
pip install -r requirements.txt

copy .env.example .env      # Windows
# cp .env.example .env      # Linux / macOS

# в .env впишите BOT_TOKEN от @BotFather и ADMIN_IDS (ваш Telegram ID)
python bot.py
```

Свой Telegram ID можно узнать, отправив боту команду `/id`.

## Структура проекта

```
bot.py               точка входа: логи, проверка настроек, запуск polling
config.py            все настройки, чтение .env, отделы и права доступа
db.py                SQLite: схема, заявки, комментарии, журнал вопросов
kb.py                база знаний: загрузка faq.json, нечёткий поиск, выбор отдела
session.py           пошаговые диалоги (telebot без FSM — своё хранилище)
ui.py                все тексты и клавиатуры
helpers.py           отправка и редактирование сообщений, уведомления
handlers_user.py     сценарии клиента
handlers_admin.py    панель поддержки
stt.py               распознавание голосовых сообщений
data/faq.json        вопросы и ответы — правится без программиста
docs/ADMIN_GUIDE.md  руководство администратора
.env.example         шаблон настроек
```

## Как это работает

Пользователь пишет вопрос своими словами. `kb.search()` нормализует текст
(регистр, `ё→е`, пунктуация), приводит слова к основам, сравнивает с вопросами
и ключевыми словами базы знаний и возвращает оценку от 0 до 1.

* оценка ≥ `FAQ_DIRECT_THRESHOLD` (0.50) — бот отвечает сразу;
* оценка ≥ `FAQ_SUGGEST_THRESHOLD` (0.20) — предлагает похожие вопросы кнопками;
* ниже — предлагает создать заявку и подсказывает подходящий отдел.

Каждый вопрос попадает в таблицу `faq_log` вместе с результатом и отзывом
👍/👎. Из этих данных строится экран «Вопросы без ответа» — готовый список для
пополнения базы знаний.

Заявки маршрутизируются по двум отделам: **технический отдел** (сайт, оплата,
личный кабинет) и **отдел продаж** (товары, заказы, доставка, возвраты).
Отдел определяется по ключевым словам, но и клиент, и сотрудник могут его
изменить.
